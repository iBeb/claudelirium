# claudelirium

Mock clinical vocabulary for failure modes that already existed but lacked names.

- `extract_nosography_post_framework_disorders.md` — Nosography of Post-Framework
  Disorders. Where it started: the habits a PHP developer carries into Go.
- `claude_superfluous_verbiage_lexicon.md` — A Lexicon of Claude's Superfluous
  Verbiage. Where it went.

The project began as a collection of programmer's diseases and drifted toward
mocking Claude instead. It is named for the drift.

All entries, including the ones mocking Claude, were polished by Claude.
