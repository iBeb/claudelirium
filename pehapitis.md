**Pehapitis (n.)** — Contracted through prolonged residence in the PHP ecosystem and typically asymptomatic for years, dormant, until the host is transplanted into Go — at which point the immune response, calibrated for an environment that no longer exists, turns on the new tissue. Presents as: reaching for a framework before a single handler has been written; a craving for a dependency-injection container so acute that its absence in `main.go` produces physical unease; modeling every payload as a nested map because arrays once solved everything; and a `Manager` that manages a `Handler` that handles a `Service`, delegation descending until the actual work is nowhere to be found. Advanced cases treat error not as a value to be checked but as an inconvenience to be wrapped and hurled upward until someone else's stack frame has to deal with it. **Epidemiology:** Endemic strictly to the PHP ecosystem, and here the family distinction matters: the lesions are polyetiological but Pehapitis proper is monogamous to PHP. It is the most complete and virulent presentation known, the only host in which both lesions reliably co-occur as a single syndrome rather than in isolation. Prevalence approaches totality among long-term PHP natives at first Go exposure and falls off sharply with years since migration, though seroconversion is rarely total. **Etiology:** sole and sufficient cause is prolonged formative exposure to the PHP framework culture, where the framework did the thinking and rewarded the host for supplying ceremony in return. No co-factor is required; PHP is enough. **Prognosis:** good, and better the earlier it is caught — read the standard library, delete two-thirds of the abstractions, and sit quietly with the discomfort of a package that simply works with nothing holding it up. Full remission is achievable; many recovered hosts nonetheless retain a lifelong flinch at an empty `main.go`. Named for the phonetic recitation of the pathogen — pe-ha-pe, the only pronounceable form — the letters themselves resisting Latin as stubbornly as the habits resist Go.
